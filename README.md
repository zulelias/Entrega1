# 🎧 Proyecto React Informatorio

**Entrega 4** del proyecto desarrollado con React + Vite, como parte del curso Informatorio Chaco.

## 📝 Descripción

Aplicación SPA desarrollada con React. Permite visualizar, crear y explorar canciones mediante una interfaz moderna y funcional. Se implementaron rutas con React Router, navegación entre vistas, manejo de estado con React Query y tipado con TypeScript.

## 🚀 Funcionalidades

- Listado de canciones con título y artista
- Visualización de detalles por canción
- Creación de nuevas canciones
- Manejo de errores y carga
- Integración con React Query para datos asincrónicos
